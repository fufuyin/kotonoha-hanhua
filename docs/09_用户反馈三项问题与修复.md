# 09 用户反馈三项问题的定位与修复

用户反馈（一次启动后）：①字体风格不对 ②行距/排版错位、文字被裁 ③角色名字是乱码，且字体颜色都变白了。

关键前提：`BepInEx\LogOutput.log`（17:39，插件 v3.0 在跑）里 **没有任何 `[GAP]`**，也就是说
**没有任何字符因为"我方字体里没有"而缺字**——所以 ③ 不是缺字，② 也不是缺字。日志还给出了
每个原字体的完整度量，直接解释了 ②。

## 一、② 行距/排版错位（已定位，已修）

v3.0 的 `[FACE]` 输出（`lineHeight / pointSize` = 行高几个 em）：

| 游戏原字体 | pointSize | lineHeight | 行高/em |
|---|---|---|---|
| Gyate-Luminescence SDF | 170 | 170 | **1.00** |
| Makinas-4-Square SDF | 48 | 48 | **1.00** |
| RiiPopkkR SDF | 40 | 40 | **1.00** |
| Stick_Regular SDF | 40 | 38.5 | **0.96** |
| （我方）KotonohaCreator | 64 | 92.672 | **1.448** |

原字体都是 **1.0 em 行高**，而我烤的 Noto 是 **1.448 em** → 用 v2.1（用户第一次看到的状态）时
**每行比原版高 45%**，固定高度的对话框必然被挤爆/裁切、基线也整体下移。这就是 ② 的根因。

修法（v3.0 已实现并已生效）：给每个原字体建一个**代理克隆**，把 `ascent/descent/lineHeight/baseline/
capLine/tabWidth` 按 `k = 我方pointSize / 原pointSize × 原scale` 归一化后继承，图集仍是同一张。
日志里 `[PROXY]` 行就是换算记录，例如：

```
[PROXY] 'Gyate-Luminescence SDF' k=0.3765 lineHeight 170->64 ascent 146.094->55 descent -23.906->-9
[PROXY] 'Makinas-4-Square SDF'  k=1.3333 lineHeight 48->64  ascent 42.25->56.333 descent -5.813->-7.75
```

（注意：用户看到裁切很可能是 16:57 那次 v2.1 的运行；v3.0 已在 17:39 那次生效。）

## 二、③ 名字乱码 + 颜色都变白（已定位，已修）

这两件事是**同一个根因的两面**：游戏会把**自己的材质预设**（跟着某个原字体的图集走）赋给文本，
而我们的替换只改了字体：

* 文本的字形矩形来自**我方图集**，但材质 `_MainTex` 仍指向**原字体图集** → 采样错图 → **乱码**（③上）
* 同一时刻，预设材质里的 `_FaceColor`/描边/关键词都被我们的新材质覆盖成默认（白 + 无色）→ **全变白**（③下）

修法（插件 v4.1）：

1. `[MAT]` 建代理材质时，从原材质**继承** `_FaceColor/_OutlineColor/_UnderlayColor/_GlowColor/
   _SpecularColor/_Reflect*` 与 `_FaceDilate/_OutlineWidth/_Underlay*/_Bevel*/_Glow*/_Weight*/…`
   以及 **shaderKeywords**（`OUTLINE_ON`/`UNDERLAY_ON`/`GLOW_ON` 等，不继承关键词等于特效关掉），
   但 `_MainTex/_TextureWidth/_TextureHeight/_GradientScale` 保持我方；
2. `[RETARGET]` 若发现某个文本的材质 `_MainTex` 仍是**游戏原图集**，就按该预设复制一份材质
   （属性+关键词照搬、图集换成我方）再挂回去 → 既修乱码也保住原本的颜色/特效；
3. `[TEXT]` 记录前 30 个文本的「原字体 → 换成的代理 → 字号 → 内容前 28 字」，
   `[FONT]` 警告「用了没有代理的字体」，用来确认名字面板到底走的哪条路。

## 三、① 字体风格（已换源重烤）

原字体是手写/像素风（Gyate-Luminescence、Stick_Regular、Makinas-4-Square、RiiPopkkR），
而 Noto Sans CJK 是无衬线黑体 → 风格不搭。

已改用 **霞鹜文楷 LXGW WenKai Regular**（SIL OFL 1.1，楷体/手写感，更贴合这类温情向同人游戏）重烤：

| 指标 | Noto Sans CJK SC | LXGW WenKai |
|---|---|---|
| cmap 覆盖 | 44,810 | **46,490** |
| 对 8,745 字符集的缺字 | 781 | **711**（全是 C1 控制符/Latin 扩展/西里尔等**任何字体都没有**的噪声码位） |
| 风格 | 无衬线黑体 | 楷体手写感 |

旧的 Noto 字库包已存档为 `_hanhua\backup\kotonoha_font.noto.bundle`，想换回黑体只要把它复制成
`BepInEx\plugins\kotonoha_font.bundle` 即可（无需重烤）。重烤脚本现在从 `F:\Application\Unity\fontsource.txt`
读源字体路径，换风格只要改这个文件再跑 `FontCreator.Bake`。
