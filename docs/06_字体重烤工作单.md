# 字体重烤工作单（路线 A）——一次性解决所有方块

> 背景：本作 5 支 TMP 字体各有独立图集与材质，**跨字体/跨图集渲染必然乱码**（已两次实测确认）。
> 因此唯一彻底的修法是：**给每支字体都烤上完整的字符集**，让任何分支、任何状态都有字形。

| 字符集文件 | **`_hanhua/out/bake_charset.txt`** —— 已备好，**8,658 码位**，已校验包含全部关键字符（`？ · Ω Д ☆ ℃ ± ＃ ％ ＠ ＆ ￥ ！ ， ～ ・ … — ー`、ASCII、全角、汉字 7,108、假名 180） |

## 二、Unity 侧的步骤

1. 新建/打开 Unity 工程，导入中文字体（把 TTF 拖进 Assets）
2. 菜单 **Window ▸ TextMeshPro ▸ Font Asset Creator**
3. 按下表填写：

| 选项 | 值 | 理由 |
|---|---|---|
| Source Font File | 你的中文字体 | |
| Sampling Point Size | **90** | 与原字体资产一致（原本 assets 记录了 90pt/1.1.0） |
| Padding | **9** | 同上 |
| Packing Method | Fast 或 Optimal | Optimal 更省空间但慢 |
| Atlas Resolution | **8192 × 8192** | 原图集就是这个尺寸；若提示放不下再考虑分两张 |
| Character Set | **Characters from File** → 选 `bake_charset.txt` | 关键 |
| Render Mode | **SDFAA** | 与游戏一致 |

4. 点 **Generate Font Atlas**，确认 **Missing Characters 为 0**（若不为 0，把提示的缺字发我，我补进字符集）
5. 点 **Save as...** 保存。**需要生成 5 份**（游戏有 5 支字体，各自要跟自己的材质配对）：

| # | 对应原资产 | 所在文件 | 原始大小 |
|---|---|---|---|
| 1 | 212484（Gyate，中文对话主字体） | `sharedassets0.assets` | 212,484 B |
| 2 | 729420（Makinas） | `sharedassets0.assets` | 729,420 B |
| 3 | 602508（RiiPopkkR） | `sharedassets0.assets` | 602,508 B |
| 4 | 622492（Stick_Regular） | `sharedassets0.assets` | 622,492 B |
| 5 | 729416（GDhwGoJA，UI 字体） | `resources.assets` | 729,416 B |

6. 导出方式（任选其一给我）：
   - **推荐**：把 Unity 工程整个目录（或 `Assets/` + `Library/`）压缩给我 —— 我直接读 `.asset` 与图集
   - 或者：用 AssetBundle 导出（BuildPipeline），把 bundle 给我
   - 或者：把生成出的 5 个 `.asset`、5 张 Atlas `.png`、5 个 Material 一起给我

## 三、我拿到后做的事

1. 按原结构把这 5 组（**字体资产 + 图集纹理 + 材质**）写回 `sharedassets0.assets`（4 支）与 `resources.assets`（1 支）
2. **保持每支字体自己的「材质 ↔ 图集」配对**（这是避免乱码的关键，也是之前两次踩坑的原因）
3. **离线校验**：逐支字体核对字符表覆盖 = 全部文本字符；核对对象数/偏移/文件有效性；文件大小变化可接受（会重算对象表）
4. 给你验收：所有方块（对话 `？`/`·`、原住民台词、图库、UI）应全部消失
