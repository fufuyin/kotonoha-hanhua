## 8. 第二轮：用户三项反馈（2026-09-12）——已查明的事实

### 8.1 材质口径（这是描边的关键，全部从原版真实数据反推并逐条验证）

| 公式 | 验证 |
|---|---|
| `_GradientScale = padding + 1` | Gyate/Makinas/GDhwGoJA = 11（padding 10）；Rii/Stick = 6（padding 5） |
| `_ScaleRatioA = 1 - 1/_GradientScale`（= padding/(padding+1)） | padding 10 → 0.909091 ✓；padding 5 → 0.833333 ✓ |
| `_ScaleRatioB = _ScaleRatioC = _ScaleRatioA × (0.8125 - _FaceDilate)` | 0.909091×0.8125=0.738636 ✓；×0.6125=0.556818 ✓；×0.5625=0.511364 ✓；×0.6625=0.602273 ✓（4 组原版数据全中） |

> TMP 的描边宽度 = `_OutlineWidth × _ScaleRatioA`。所以 `_ScaleRatioA/B/C` **属于几何口径，必须与图集 padding 一致**，
> 不能当成"风格值"照抄。

### 8.2 补丁作者改过的唯一材质数值

`diff_materials.py`（按 pathID 对齐逐属性比对）结果：原版 → 补丁 **只有 1 处差异**：
`Gyate-Luminescence SDF Material (0x1a)` 的 `_OutlineWidth` `0.0 → 0.3`（`_OutlineColor` 是白色）。

* 这正是"金币描边太重"的来源（原版该材质根本没有描边）。
* **已修**：`_OutlineWidth` 0.3 → **0.15**（`patch_mat_float.py` + `install_assetfix.ps1 -TestFile`）。
  校验：193 对象、对象表一致、前后缀逐字节一致、fileSize 头一致 → PASS。

### 8.3 我们 bundle 材质的缺陷（插件代理材质的模板）

`KotonohaCreator Material`：`_GradientScale=11` ✓ 但 **`_ScaleRatioA=B=C=1`** ✗（应为 0.909091 / 0.738636）、`_Sharpness=0`。

插件 `KotonohaCNFontV2.cs` 的 `KeepOurs` 明确把 `_ScaleRatioA/B/C` 保留成"我们的"（第 217-221 行），
只从游戏材质继承 `_OutlineWidth/_FaceDilate/颜色/关键字` → **代理材质的几何口径必然偏差**。
这是问题 1/2（文字/菜单没描边）的首要嫌疑：应当让这几项也用游戏/正确值，或干脆去掉插件走资产级。

### 8.4 原版字体资产的尾部布局与我们的 payload **不完全一致**（重要风险）

尾部结构实测：`[-272: i32 count=10][-268:-28: m_FontWeightTable 240B][-28:-16: null PPtr][-16: 样式4值]`

| 资产 | 权重表 count 位置 | 备注 |
|---|---|---|
| 我们的 payload / 补丁的 Gyate / Rii / Stick | `-272` ✓ | 与我们同构 |
| **原版 Makinas(0xbf) / GDhwGoJA(0x80b9)** | **`-268`** ✗ | 尾部比我们多 4 字节 |
| 原版 Rii/Stick | `-272` ✓ | 但 `-336..-272` 多一段 GUID/路径字符串 |

**结论：不能把我们的 payload 无脑替换给 Makinas/GDhwGoJA**（字段可能错位）——必须先解决这 4 字节差异，
或者改用不重建 payload 的机制（见 8.6）。

### 8.5 菜单字体（问题 2 的对象）

* `GDhwGoJA-OTF112b2 SDF`：MonoBehaviour **0x80b9**（729,416B，在 `resources.assets`）
* 图集 `GDhwGoJA-OTF112b2 SDF Atlas`：**0x1ff3，只有 148 字节 → 像素流式存放**在
  `resources.assets.resS` 的 **offset=851,443,740、size=67,108,864（8192² Alpha8，正好等于我们图集）** → **可原地覆盖** ✓
* 它的材质一族（`GDhwGoJA-OTF112b2 SDF_save` 等）本身就是 `_GradientScale=11 / _ScaleRatioA=0.909091 / 8192²` → 口径与我们一致 ✓
