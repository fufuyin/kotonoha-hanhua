## 五、字体侧本轮改动（配合 07）

插件升级到 v3.0 并在游戏里生效（原文见 `_hanhua/plugin/KotonohaCNFontV2.cs`）：
- 不再「所有文本套同一个字体」，而是**给游戏每个原字体建一个代理（proxy）克隆**：
  图集仍是同一张（内存不变），但 `faceInfo` 的 ascent/descent/lineHeight/baseline/capLine 按
  `k = 我方pointSize / 原pointSize × 原scale` 归一化后继承 → **行距与垂直排版跟原字体一致**，
  避免行距变大导致文本框裁切；
- 每个代理用独立材质实例（贴近原「每字体一材质」的结构）；
- 新增诊断：`[FACE]` 打印游戏原有每个字体的完整度量、`[PROXY]` 打印换算结果、
  `[GAP]` 打印**我方字体缺哪个字符**（没有截图也能知道哪里还会缺字）。
- 兜底：原字体度量不可用（pointSize/lineHeight ≤ 0）或代理创建失败 → 自动退回 v2.0 行为（已知可用）。
